# Tasks

[GitHub Issues](https://github.com/hleserg/Attadipa/issues) are Attadipa's only
task queue. An issue owns its scope, acceptance criteria, dependencies,
assignee and blockers. A linked pull request owns implementation status and
test evidence.

Do not copy an issue into this file and do not update this file per task. Use
[`docs/ROADMAP.md`](docs/ROADMAP.md) only for durable product ordering; Git and
closed issues preserve completed history.
