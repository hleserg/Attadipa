# Seed discussions

Three worked examples of the app-idea form
([`.github/DISCUSSION_TEMPLATE/ideas.yml`](../../../.github/DISCUSSION_TEMPLATE/ideas.yml)),
filled in the way we hope a thoughtful contributor would fill it.

They live here because **creating a GitHub Discussion is a GraphQL-only
operation** (`createDiscussion`), and the agent session that wrote them had
GraphQL disabled. Each file is the complete body of one Discussion, ready to be
posted into the **Ideas** category with the title given at the top.

They are ideas, not commitments. Nothing here describes a capability Firefly
already has — see [STATUS.md](../../../STATUS.md) for what actually exists,
which today is a simulator and no firmware.

Once posted, these files can be deleted or left as a style reference. They are
not a second copy of the Discussions; they are the seed.
