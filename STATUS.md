# Project status

Live status is not committed to a shared Markdown ledger:

- [open issues](https://github.com/hleserg/Attadipa/issues) are the work queue
  and hold acceptance criteria and blockers;
- [open pull requests](https://github.com/hleserg/Attadipa/pulls) show claimed
  and in-progress work;
- each pull request's checks and review show whether it is ready to merge;
- [`docs/ROADMAP.md`](docs/ROADMAP.md) holds durable product direction.

Do not update this file for an individual task or release. Historical status is
already preserved by Git, closed issues and merged pull requests.
